# Security Policy

swift-raster-webp processes untrusted files, so memory-safety and denial-of-service problems are treated as security issues.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/BZsombor/swift-raster-webp/security/advisories/new). Do not open a public issue.

Include the affected version, the platform, and a file or steps that reproduce the problem.

## Supported versions

Until the 1.0 release, only the latest release receives security fixes.
